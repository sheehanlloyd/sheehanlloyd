## 🛠 Projects

<table>
<tr><td>

### [Chronos](https://github.com/sheehanlloyd/chronos) &nbsp; <img src="https://img.shields.io/badge/Rust-000000?style=flat-square&logo=rust&logoColor=white" alt="Rust">

**A reverse-execution debugger for AArch64 Linux.** Set a breakpoint, run past a crash, then step *backwards* to the instruction that corrupted your pointer.

Built from raw `ptrace` up — software `BRK` breakpoints, DWARF line/type/CFI parsing, checkpoint-and-replay via clone injection, and a web UI with a scrubbable execution timeline. Seven crates, no external debugger dependencies.
